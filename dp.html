กำหนดการพลวัต (DP) ลองเล่น

ตามเนื้อหาสัปดาห์ 7–8: ตารางกระเป๋า (ชุดซ่อมฉุกเฉิน) และการทอนเงิน กดไล่ทีละช่อง ดูว่าแต่ละช่องมาจากช่องไหน แล้วเปลี่ยนตัวเลขเองได้

1นิยามหนึ่งช่องเป็นประโยค
เช่น F[x] = จำนวนเหรียญน้อยสุดที่รวมได้ x บาท
2ลองทุกทางเลือกของช่องนั้น
แต่ละทางไปอ่านค่าจากช่องที่เล็กกว่า (ที่เติมไว้แล้ว) แล้วเก็บทางที่ดีสุด
3เติมจากกรณีฐานขึ้นไป
แล้วย้อนรอยหาว่าเลือกอะไรบ้าง

ทอนเงิน: เหรียญแต่ละแบบใช้ได้ไม่จำกัด ใช้เหรียญน้อยที่สุด

คำถามท้ายคาบ: ทอน 6 บาทด้วย {1, 3, 4} เปรียบเทียบวิธีละโมบกับวิธีจดคำตอบย่อย

สีฟ้าประ = ช่องที่กำลังอ่านค่า · เหลือง = ช่องที่กำลังคำนวณ · เขียว = เติมแล้ว (กดช่องที่เติมแล้วเพื่อกระโดดไปดู)

ตารางกระเป๋า: เลือกของให้ประโยชน์สูงสุด หยิบแต่ละชิ้นได้ครั้งเดียว

F[i, w] = ประโยชน์มากสุด เมื่อใช้ได้เฉพาะของ i ชิ้นแรก และรับน้ำหนักได้ไม่เกิน w

เหลือง = ช่องที่กำลังคำนวณ · ฟ้าประ = ทางไม่เอา (ช่องข้างบน) · ส้มประ = ทางเอา (ช่องข้างบน ซ้ายไป wᵢ) · กดช่องที่เติมแล้วเพื่ออ่านความหมายเป็นประโยค

ใบงาน 10 ข้อ ลองทำบนกระดาษก่อน แล้วเปิดเฉลย

ลำดับการเขียนที่อาจารย์ให้: คำถามเป็นภาษาคน → หน่วยข้อมูล → ตัวเลือกพร้อมตัวเลข → ผลที่เก็บ → เหตุผลตรวจสอบ ข้อความโจทย์ย่อมาจากใบงานของอาจารย์ เฉลยเขียนเองและตรวจด้วยโปรแกรมแล้ว ถ้าต่างจากที่อาจารย์เฉลย ให้ยึดอาจารย์

เขียนเป็นโค้ดแบบ RAM

ในสไลด์ อาร์เรย์เริ่มที่ 1 แต่ตารางในหนังสือเริ่มที่ 0 จึงเลื่อนที่อยู่ไป +1 เช่น F[3,7] เก็บที่ M[4][8] และ F[x] เก็บที่ Count[x+1]

กระเป๋า (F[i,w])

declare W[1..n], V[1..n], M[1..n+1][1..C+1]
declare i, capacity, j, itemWeight, itemValue, skip, take
for j ← 1 to C+1
    M[1][j] ← 0
for i ← 1 to n
    itemWeight ← W[i]
    itemValue ← V[i]
    for capacity ← 0 to C
        skip ← M[i][capacity+1]
        if itemWeight ≤ capacity then
            take ← itemValue + M[i][capacity-itemWeight+1]
            if take > skip then skip ← take
        M[i+1][capacity+1] ← skip
return M[n+1][C+1]

ตาม trace หนึ่งช่อง i = 4, capacity = 7 (D = (5,7)): อ่าน W[4] = 5, V[4] = 7 · อ่าน skip = M[4][8] = 9 · เทียบ 5 ≤ 7 จริง · อ่าน M[4][3] = 1 แล้วคำนวณ take = 7 + 1 = 8 · เทียบ 8 > 9 เท็จ · เขียน M[5][8] ← 9 งานคงที่ต่อช่อง (read, arithmetic, comparison, write) ตาราง (n+1)(C+1) ช่อง จึงใช้เวลาและพื้นที่ Θ(nC) เป็นเวลาพหุนามเทียม เพราะ C คือค่าตัวเลข ไม่ใช่จำนวนบิต

ทอนเงิน (F[x])

declare Coins[1..k], Count[1..Amount+1], Last[1..Amount+1]
declare x, j, coinValue, candidate, best, chosenCoin
Count[1] ← 0
for x ← 1 to Amount
    best ← Amount+1
    chosenCoin ← 0
    for j ← 1 to k
        coinValue ← Coins[j]
        if coinValue ≤ x then
            candidate ← 1 + Count[x-coinValue+1]
            if candidate < best then
                best ← candidate
                chosenCoin ← coinValue
    Count[x+1] ← best
    Last[x+1] ← chosenCoin
return Count[Amount+1]

โค้ดนี้ใส่บรรทัด chosenCoin ← coinValue เองให้ครบ (ในสไลด์ของอาจารย์ที่ผมอ่านได้ไม่เห็นบรรทัดนี้ แต่ต้องมี ไม่งั้น Last จะเป็น 0 ตลอด) และสมมติว่ามูลค่าเป็นจำนวนเต็มบวกพร้อมเหรียญ 1 จึงทอนได้ทุกยอด

trace ยอด 7: best = 11 · เหรียญ 1: Count[7] = F[6] = 2 → candidate 3 → best = 3 · เหรียญ 3: Count[5] = F[4] = 1 → candidate 2 → best = 2, chosenCoin = 3 · เหรียญ 4: Count[4] = F[3] = 1 → candidate 2 ไม่น้อยกว่า 2 จึงไม่เปลี่ยน · เขียน Count[8] ← 2 และ Last[8] ← 3 (2 คือจำนวนเหรียญ ส่วน 3 คือมูลค่าเหรียญ)

ย้อนคำตอบ: remaining ← Amount; while remaining > 0: coinValue ← Last[remaining+1]; output coinValue; remaining ← remaining − coinValue ลดยอดด้วยมูลค่าเหรียญ ไม่ใช่ลดทีละ 1 เวลาเติมตาราง Θ(Amount × k) พื้นที่ Θ(Amount)
